# Other Side — Beyond infrastructure.

Sitio institucional y portfolio inicial de Other Side.

## Estado

Primera versión estática, bilingüe (español/inglés) y responsive. El contenido distingue capacidades y líneas de exploración de proyectos comerciales implementados. No se atribuyen clientes, contratos ni despliegues que no hayan sido confirmados.

## Desarrollo local

No requiere Node.js ni dependencias.

1. Clonar el repositorio.
2. Abrir `index.html` en un navegador.
3. Para desarrollo con recarga automática, usar cualquier servidor estático local.

## Publicación

Puede publicarse con GitHub Pages desde la rama `main`, usando la carpeta raíz (`/root`). En GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Pendientes antes de publicar como sitio comercial definitivo

- Confirmar disponibilidad jurídica y comercial de la marca Other Side.
- Definir dominio y correo corporativo reales.
- Reemplazar el enlace de GitHub de la sección de contacto por un canal comercial confirmado.
- Incorporar proyectos, imágenes y casos verificables a medida que estén listos.
- Revisar textos, accesibilidad y metadatos para SEO.

## Principios de comunicación

No presentar prototipos como productos desplegados. No inventar clientes, certificaciones, alianzas, métricas ni experiencia. Identificar con claridad investigación, desarrollo y soluciones implementadas.
